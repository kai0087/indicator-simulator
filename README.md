# 指示ビラ・レイアウトシミュレータ

![version](https://img.shields.io/badge/version-1.0.0-blue)
![license](https://img.shields.io/badge/license-MIT-green)

製造ラインの「指示ビラ」（作業の指示を示すマス目の表示）のレイアウトを、スマホやパソコンで作って確認・印刷・共有できるWebアプリです。
インストールは不要で、ブラウザで開いて、ホーム画面に追加すれば、電波が弱い場所でも使えます。

## 使ってみる

**https://kai0087.github.io/indicator-simulator/**

### スマホのホーム画面に追加する

1. 上のアドレスをスマホのブラウザで開く（**最初の1回だけ電波が必要**です）
2. ホーム画面に追加する
   - iPhone（Safari）：共有ボタン → 「ホーム画面に追加」
   - Android（Chrome）：右上のメニュー → 「ホーム画面に追加」（または「アプリをインストール」）
3. 以降はホーム画面のアイコンから開く（電波がなくても開けます）

## できること

| 機能 | 内容 |
| --- | --- |
| 車型タブ | L4 / V6 / GD をワンタップで切り替え。車型ごとに行・列を別々に設定できます |
| マス目の設定 | 行・列（各1〜10）、文字サイズ（小・中・大） |
| マスの編集 | 作業名、表示文字（最大2文字）、背景色（10色）。マスは左右2分割もできます |
| 保存・読込 | 1工程ぶん（3車型まとめて）を名前をつけて端末に保存します |
| 保存前の確認 | 「アカ」と書いたのに背景が「アオ」など、文字と背景色が合っていないマスを警告します |
| QR共有 | 送りたい車型にチェックを入れてQRコードを作ります。相手がスマホのカメラで読み取ると、そのビラが表示されます |
| 印刷／PDF | 表示中の車型1枚を印刷またはPDFにできます |

## 基本の使い方

1. 画面上のタブで車型（L4 / V6 / GD）を選ぶ
2. 「行」「列」で、マスの数を決める
3. マスをタップして、右側（スマホでは下側）の編集欄で、作業名・文字・背景色を設定する
4. 工程名をつけて「現在の配置を保存」を押す
5. 他の人に渡すときは「共有/QR」を押して、送りたい車型にチェックを入れ、QRコードを見せる

### QRコードを受け取る側

- スマホの標準カメラでQRコードを読み取り、表示されたアドレスを開きます
- 受け取った内容を残したいときは、「現在の配置を保存」を押してください
- 「アプリが古い可能性があります」と出たら、電波のある場所でアプリを開き直して、最新版にしてください

## 注意事項

- 保存したデータは、**使っている端末のブラウザの中だけ**に残ります。他の端末へは自動では移りません（QR共有を使ってください）
- ブラウザの閲覧データを消すと、保存したレイアウトも消えることがあります
- ブラウザで開いた場合と、ホーム画面のアプリで開いた場合では、保存データが別々になることがあります（特にiPhone）
- QRコードに入れられるデータ量には上限があります。大きすぎるときは、チェックする車型を減らしてください
- このリポジトリは公開されます。**社外秘の情報（実際の工程名・品番など）は、README・設定ファイル・サンプルに書かないでください**
  - 保存したレイアウトは端末の中だけに残り、GitHubには送られません。QRコードのデータも、アドレスの後ろに付くだけで、サーバーには送られません

## 管理者向け：更新のしかた

1. 変更した `index.html` と `sw.js` を、このリポジトリの同じ名前のファイルに上書きします
   - GitHubのリポジトリ画面で「Add file」→「Upload files」→ ファイルをドラッグ → 「Commit changes」
2. **`sw.js` の `VERSION` の数字を必ず上げてください**（上げないと、端末が古い画面を使い続けます）
3. 数分待つと、GitHub Pagesに反映されます
4. 使う人は、電波のある場所でアプリを開き直すと、新しい版になります（反映に、2回開き直す必要がある場合があります）

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（画面・動き・QR生成ライブラリを含む1ファイル） |
| `sw.js` | オフライン動作のための裏方のファイル（Service Worker） |
| `manifest.webmanifest` | ホーム画面に追加するときの名前・色などの設定 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン画像 |
| `README.md` | このファイル |
| `CHANGELOG.md` | 変更履歴 |
| `LICENSE` | ライセンス（MIT） |
| `THIRD_PARTY_LICENSES.md` | 組み込んだライブラリの権利表記 |

## 動作環境

- 最近のiPhone（Safari）・Android（Chrome）・パソコンのブラウザ
- 外部のサービスやサーバーには接続しません（すべて端末の中で動きます）
